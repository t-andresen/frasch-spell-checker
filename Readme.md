# North Frisian Spell Checker - Mooringer Frasch

A basic spell checker based on the vocabulary recorded in the Frasch Uurdebök dictionary. Word forms have been generated automatically from it according to the grammatical rules. Like the dictionary, the spell checker focuses on the Ååstermooring variety, though it does contain some other word forms from the Bökingharde dialect group.

Changes made to the base dictionary data:
* some mistakes have been corrected
* some german loanwords have been left out

Additions on top of the dictionary data:
* some words not covered by the dictionary have been added
* some common word variants have been added
* frisian place names and geographic terms have been added
* a small pool of common names have been added, including object and genetive forms

Current gaps:
* hyphenation
* word composition
* participle adjective forms

Created with the kind permission of the North Frisian Dictionary Unit (Nordfriesische Wörterbuchstelle) at Kiel University (Christian-Albrechts-Universität zu Kiel), based on the language data from the 1st edition (1988) of the Frasch Uurdebök. A retro-digitized edition of the 2nd edition (2002) of the dictionary is available in the NordDok collection on the MACAU publication server of Kiel University Library: https://doi.org/10.38071/2025-01302-7.
